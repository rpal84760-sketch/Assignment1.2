How a Website Opens on the Screen (Explanatory Paragraph)When you type a URL into your browser (acting as the client), the browser uses DNS to find the IP address of the server hosting the website, and then sends an HTTP/HTTPS request across the internet using the request-response cycle; the server receives this request—often fetching stored data from a database if it is a dynamic site—and sends back the HTML, CSS, and JavaScript files as a response, which the browser then interprets, renders, and displays on your screen.2. Meanings of HTTP and HTTPSHTTP (HyperText Transfer Protocol): The foundational protocol used for transmitting hypermedia documents (such as HTML) across the World Wide Web. Data is transferred in plain text, making it vulnerable to interception.HTTPS (HyperText Transfer Protocol Secure): The secure version of HTTP. It uses SSL/TLS encryption to encrypt the data transferred between your browser and the web server, protecting sensitive information (like passwords and credit card details) from eavesdroppers.3.
